## 📌 Project Overview

This project focuses on learning JavaScript DOM Manipulation by creating interactive web pages and a functional To-Do List application.

The project demonstrates how JavaScript can select, modify, create and remove HTML elements dynamically.

## 🚀 Main Project: To-Do List

A responsive To-Do List application that helps users organize and manage their daily activities.

### Features

* Add tasks using the button or Enter key.
* Prevent empty task submissions.
* Mark tasks as completed.
* Undo completed tasks.
* Delete individual tasks.
* Filter tasks by All, Active and Completed.
* Display the number of remaining tasks.
* Clear all completed tasks.
* Double-click to edit tasks.
* Save edits using Enter or cancel using Escape.

## 📚 Lessons Learned

During this week, the following concepts were practiced:

1. **DOM Selection:** Using `querySelector()` and other DOM methods to select HTML elements.
2. **Event Handling:** Using `addEventListener()` to respond to user interactions.
3. **Event Delegation:** Using one event listener on the task list so newly created tasks work without adding individual listeners.
4. **Dynamic Elements:** Using `createElement()` to create HTML elements with JavaScript.
5. **Safe Text Handling:** Using `textContent` instead of `innerHTML` to display user-entered tasks safely.
6. **CSS Classes:** Using `classList` to add, remove and toggle CSS classes.
7. **Arrays and Objects:** Storing tasks as objects inside an array and updating the displayed list.
8. **Keyboard Events:** Using Enter and Escape keys to save or cancel task editing.
